Data notice

개인정보 처리 안내

1. 서비스 구성

도구 디렉터리는 정적 페이지로 제공되며, 다운로드 버튼은 각 도구의 외부 공식 제공처로 연결됩니다.

2. 온라인 기능

관리자 인증, 공용 메모와 그룹 채팅 기능에는 Supabase가 사용됩니다. 해당 기능에 입력한 인증 정보, 닉네임, 메모 및 채팅 내용은 기능 제공을 위해 외부 서버로 전송될 수 있습니다.

3. 명언 번역

명언의 한국어 번역을 불러올 때 원문이 Google 번역 엔드포인트로 전송될 수 있습니다.

4. 외부 서비스

외부 다운로드 페이지에서는 각 서비스 제공자의 개인정보 처리방침과 이용 조건이 적용됩니다. 메모와 채팅에는 민감한 정보를 입력하지 마세요.
